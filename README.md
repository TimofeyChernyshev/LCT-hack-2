## 🌟 Ключевые преимущества и механики

1. **Обратная механика подбора (LHH — Lee Hecht Harrison):**
   * Инициативу выхода на контакт проявляет работодатель, находя нужную категорию кандидатов в базе;
   * Автоматическое маскирование контактных данных соискателя (`Contacts.Mask()`) до момента явного согласия;
   * Обязательное указание прозрачной зарплатной вилки в рублях («от–до») в каждом приглашении и вакансии.
2. **Адаптивное защищенное тестирование и античит:**
   * Параметрическая шаблонизация заданий с формулами и динамической генерацией чисел;
   * Серверный таймер сессии и защита от утечки правильных ответов;
   * Правило сохранения квалификации: неуспешная сдача не понижает грейд принудительно;
   * Кулдаун пересдачи до 90 дней для защиты от брутфорса.
3. **Верифицированный профиль участника ФСП:**
   * Интеграция с реестром спортивных разрядов, рейтингов и побед в хакатонах ФСП;
   * Готовность к интеграции с SSO ФСП ID на базе Keycloak (OAuth2 / OIDC);
   * Корректная и нейтральная обработка соискателей без истории в ФСП.
4. **Многофакторное ранжирование с объяснимостью (Explainable AI / XAI):**
   * Формула ранжирования: тестирование ($40\%$) + ФСП ($25\%$) + стек ($25\%$) + активность ($10\%$);
   * Человекочитаемое обоснование попадания кандидата в подборку для рекрутера прямо в карточке.
5. **Автоматический парсинг и брендированный экспорт PDF:**
   * NLP-извлечение стека, контактов и опыта из загружаемых соискателем PDF-резюме;
   * Автогенерация официального стандартизированного PDF-профиля со знаком качества ФСП.
6. **Дополнительный функционал и бонусы (7% оценки):**
   * Прямая публикация вакансий работодателями и отклики кандидатов;
   * Регулярные мини-задания от работодателей для поддержания актуальности профиля;
   * Проработанная концепция защиты от фиктивных вакансий (KYB, антифрод зарплат) и интеграции с ATS (1C:ЗУП, Huntflow).

## 🚀 Быстрый запуск (Quick Start)

Запуск всего контура платформы (7 микросервисов, PostgreSQL, Nginx, MailHog, Swagger UI, Frontend) выполняется в **2 команды**:

```bash
# 1. Сборка и запуск контейнеров в фоновом режиме
docker compose up --build -d

# 2. Инициализация демонстрационных данных и запуск психометрической валидации
python3 seed.py --run-validation
```

### Доступ к сервисам платформы:
| Сервис | URL | Назначение |
|---|---|---|
| **Веб-интерфейс платформы** | [http://localhost:5173](http://localhost:5173) | Личные кабинеты кандидата и работодателя |
| **Единый Swagger UI** | [http://localhost:8081](http://localhost:8081) | Интерактивная документация всех микросервисов API |
| **Почтовый сервер MailHog** | [http://localhost:8025](http://localhost:8025) | Просмотр писем с подтверждением email при регистрации |
| **API Gateway (Nginx)** | [http://localhost:8080](http://localhost:8080) | Проксирование всех API методов и статики |

## 🏛 Архитектура решения

Платформа спроектирована по принципам Domain-Driven Design (DDD) и микросервисной архитектуры:

```
[ Frontend: React 19 / TypeScript / TailwindCSS ]
                        │
                        ▼ (HTTP REST)
[ Nginx API Gateway :8080 ]
   ├── /api/auth/        ──> [ auth-service :8080 ]        ──> ( auth_db )
   ├── /api/candidate/   ──> [ candidate-service :8080 ]   ──> ( candidate_db )
   ├── /api/employer/    ──> [ employer-service :8080 ]    ──> ( employer_db )
   ├── /api/testing/     ──> [ testing-service :8080 ]     ──> ( testing_db )
   ├── /api/interaction/ ──> [ interaction-service :8080 ] ──> ( interaction_db )
   ├── /api/search/      ──> [ search-service :8080 ]      ──> ( search_db )
   ├── /api/dict/        ──> [ dict-service :8080 ]        ──> ( dict_db )
   └── /api/fsp/         ──> [ fspmock-service :8080 ]
```
